# shaiqa.kz

Демо-интерфейс заказов музыки для баров, ресторанов, лаунжей и караоке. Гость сканирует QR, выбирает трек и либо предлагает сумму DJ, либо в режиме «Прямой заказ» платит фиксированную цену заведения, без своей ставки. Данных карт, стриминга и запросов к серверу нет: всё лежит в `localStorage` этого браузера.

Интерфейс на русском. Числа и даты — `ru-KZ`, время — `Asia/Almaty`, суммы — тенге (₸). Словарь `src/shared/i18n` готов принять казахские строки: переключатель KK подставляет то, что уже переведено, остальное остаётся на русском.

## Запуск

```bash
npm install
npm run dev
```

Приложение слушает только `http://127.0.0.1:4731`.

Проверки:

```bash
npm run typecheck
npm run lint
npm run build
```

`VITE_API_BASE_URL` в `.env.example` равен `http://localhost:8080/api/v1`. Этот адрес нигде не вызывается. Он показан в демо-админке как зарезервированный.

## Сценарии

1. **Главная.** Заголовок, переключатель DJ Mode / Прямой заказ и живая панель заказа, не картинка. «Попробовать демо» и «Посмотреть для DJ» ведут в продукт.
2. **DJ Mode.** Откройте `/v/loft-47`, выберите трек, предложите сумму не ниже минимума (есть быстрые суммы и своё поле). Заявка становится `PENDING`. В `/dj/requests` примите её в очередь или отклоните. После отказа гость на `/request/:id` видит учебный текст: деньги в демо не списывались, это не возврат.
3. **Прямой заказ.** `/v/nochnaya-kuhnya` — без поля ставки: гость выбирает трек и платит цену заведения. Дальше `/v/nochnaya-kuhnya/checkout/:id` без полей карты. После подтверждения трек в очереди, на статусе видна позиция. Готовый черновик: `/v/nochnaya-kuhnya/checkout/draft_kitchen_demo`.
4. **Очередь DJ.** `/dj/queue` — перетаскивание и кнопки «Выше» / «Ниже», «В эфир», «Завершить». Трек в эфире остаётся первым.
5. **Заведение.** `/venue/settings` меняет фразу, режим, минимум и открытость. Обновите гостевую страницу того же заведения — она читает те же данные. `/venue/catalog` ищет, фильтрует жанр, меняет цену, прячет и добавляет демо-треки. `/venue/qr` строит код на текущий адрес гостевой, копирует ссылку, скачивает PNG и печатает карточку «Сканируй и заказывай музыку».
6. **Сброс.** «Сбросить демо-данные» в подвале, палитре или админке спрашивает подтверждение и возвращает исходный набор. Повреждённый JSON в хранилище тоже заменяется набором.
7. **Навигация.** `Cmd+K` или `Ctrl+K`, либо кнопка «Открыть навигацию». Неизвестный адрес показывает 404.

Прямые адреса, которые живут в исходных данных до сброса: `/request/req_loft_pending_a`, `/dj`, `/venue`, `/admin`, `/demo`.

## Ограничения

Это фронтенд-демо. Нет настоящей оплаты, возвратов, авторизации, лицензий и аудио. Исполнители — только подписи. Обложки с битым адресом заменяются инициалами. Казахский язык подключён структурой, не полным переводом.
