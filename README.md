# terbel.kz

Заказы музыки для баров, ресторанов, лаунжей и караоке. Гость сканирует QR, выбирает трек и либо предлагает сумму DJ, либо в режиме «Прямой заказ» платит цену заведения.

Интерфейс на русском. Числа и даты — `ru-KZ`, время — `Asia/Almaty`, суммы — тенге (₸). Словарь `src/shared/i18n` готов принять казахские строки: переключатель KK подставляет то, что уже переведено, остальное остаётся на русском.

## Запуск

```bash
npm install
npm run dev
```

Приложение слушает только `http://127.0.0.1:4731`.

Проверки:

```bash
npm run typecheck
npm run lint
npm run build
```

`VITE_API_BASE_URL` в `.env.example` равен `http://localhost:8080/api/v1`. Интерфейс этот адрес не показывает и не вызывает.

## Сценарии

1. **Главная.** Заголовок, переключатель DJ Mode / Прямой заказ и панель заказа. «Заказать в DJ mode» открывает `/v/loft-47`. «Заказать по цене заведения» открывает `/v/nochnaya-kuhnya`. «Пульт DJ» открывает `/dj`. «Кабинет заведения» открывает `/venue`.
2. **DJ Mode.** Откройте `/v/loft-47`, выберите трек, предложите сумму не ниже минимума. Заявка становится `PENDING`. В `/dj/requests` примите её в очередь или отклоните. После отказа гость на `/request/:id` видит статус «Отклонена» и текст о возврате.
3. **Прямой заказ.** `/v/nochnaya-kuhnya` — гость выбирает трек и платит цену заведения на `/v/nochnaya-kuhnya/checkout/:id`. После оплаты трек в очереди, на статусе видна позиция.
4. **Очередь DJ.** `/dj/queue` — перетаскивание и кнопки «Выше» / «Ниже», «В эфир», «Завершить». Трек в эфире остаётся первым.
5. **Заведение.** `/venue/settings` меняет фразу, режим, минимум и открытость. `/venue/catalog` ищет, фильтрует жанр, меняет цену, прячет и добавляет треки. `/venue/qr` строит код на гостевую страницу, копирует ссылку, скачивает PNG и печатает карточку «Сканируй и заказывай музыку».
6. **Вход.** `/login` — почта и пароль, без списка учёток на экране. Оператор `operator@terbel.kz` / `demo-admin` открывает `/admin`. Владельцы: `loft@terbel.kz` / `demo-loft`, `kitchen@terbel.kz` / `demo-kitchen`, `samal@terbel.kz` / `demo-samal`, `karaoke@terbel.kz` / `demo-karaoke`, `reka@terbel.kz` / `demo-reka`. Гостевые страницы остаются без входа.
7. **Навигация.** `Cmd+K` или `Ctrl+K`, либо кнопка «Открыть навигацию». Неизвестный адрес показывает 404.

Прямые адреса, которые живут в исходных данных до сброса: `/request/req_loft_pending_a`, `/dj`, `/venue`, `/admin`, `/demo`.

## Ограничения

Интерфейс говорит языком готового сервиса. Оплата, возвраты и каталог считаются в браузере, без платёжного провайдера, стриминга и лицензий. Обложки с битым адресом заменяются инициалами. Казахский язык подключён структурой, не полным переводом.
